
# PriceLab

A simple C++ application for financial asset analysis.

## Overview

PriceLab analyzes historical asset prices from CSV files
and calculates basic financial metrics.

## Features

- Load historical prices from a CSV file
- Calculate total return
- Calculate maximum drawdown

## Technologies

- C++17
- CMake
- GoogleTest
- Google Benchmark
- Doxygen
- GitHub Actions
